# Hedef Takvimi ✗

Hedeflerini yaz, gününü planla, yaptıkça çarpı at. Türkçe ve İngilizce.

- `www/`: uygulamanın kendisi (web sürümü, PWA)
- `android/`: Google Play için Android projesi (Capacitor)
- `store/`: mağaza metinleri
- `.github/workflows/`: web sürümünü GitHub Pages'e yayınlar, Android paketini (.aab) derler
